# Superseded generated banner designs

These prompts document the earlier generated banners, which have been replaced. The current set is built from Minecraft's native bitmap letter shapes and existing icon artwork; see README.md and build-banners.cjs. The old generation prompts are retained here as history and are not used to create the current assets.

## Modern screen

File: `modern-screen.png`

```text
Use case: ads-marketing.
Asset type: finished section-heading image for a Minecraft mod description on Modrinth.
Create ONE exceptionally clean, polished horizontal pixel-art heading banner. This is the first of a matching four-banner set. Render a very wide thin 6:1 strip, ideally 1800 by 300 pixels, edge-to-edge, with no surrounding canvas, no mockup, no screenshots, no title sheet.
Exact text, spelled verbatim: "MODERN SCREEN".
The large heading is the primary subject: crisp squared Minecraft-inspired bitmap lettering in warm white, readable at mobile size, generous breathing room, subtle hard dark pixel shadow, no 3D extrusion. Keep the text on a single line.
Layout: simple charcoal rectangular panel with small stepped pixel corners, a restrained one-pixel light edge, quiet near-black stone texture, tiny muted gold and diamond-teal highlights at the lower edge. Small flat pixel-art advancement-tab icon to the left of the words. The panel should feel hand-designed and close to vanilla Minecraft UI. Strong contrast, disciplined spacing, minimal ornament.
Only the requested words. No additional labels, no branding, no numbers, no watermark. Avoid cinematic lighting, glow, glossy surfaces, gradients, AI fantasy illustration, excessive ores, busy details or noisy texture.
```

## What's left

File: `requirements.png`

```text
Use case: ads-marketing. Create one finished Minecraft mod section-heading banner by editing the supplied reference banner.
Reference image role: style and layout template. Preserve the exact panel size, composition, black surrounding area, border/corners, charcoal pixel texture, white bitmap font style, flat dark pixel shadow, and restrained gold/teal accents. This must look like the same coherent graphic set, not a redesign.
Change only the heading and the left icon. Replace all existing heading text with exactly "WHAT'S LEFT" on one centered single line. Large, crisp, highly legible pixel lettering with carefully even spacing. Replace the monitor icon with a simple pixel-art checklist with two small emerald-green ticks and a few white lines, occupying the same left icon slot.
Keep the banner perfectly horizontal, clean, minimal and hand-designed. Do not add any other words, badges, branding, numbers, glow, 3D extrusion, photorealism or watermark.
```
